## Project at a Glance

- **Name:** GodFather Backend  
- **Type:** REST API + WebSockets for an AI-assisted branding questionnaire platform  
- **Stack:** Django, Django REST Framework, JWT, Celery, Redis, Elasticsearch, OpenAI, Django Channels  

Use the documents above for a complete picture. Start with **GETTING_STARTED.md** if you are new to the repo.
